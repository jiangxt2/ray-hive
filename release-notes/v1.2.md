# ray-hive 1.2

`ray-hive` 1.2 extends the documented Ray Data compatibility window through Ray 2.59.0.

## Highlights

- Support final Ray releases from 2.55.1 through the 2.59.x line.
- Add Python 3.12 and 3.13 CI baselines for Ray 2.59.0.
- Validate the Ray 2.59.0 runtime against HiveServer2 and the strict multi-node read contract.

## Compatibility

- Python 3.12 and 3.13.
- Final Ray releases `>=2.55.1,<2.60`.
- PyArrow 19.0.1, Thrift 0.22.0, and Apache Hive 4.2.0.
- Ray 2.60 and later, prereleases, development builds, and post-releases remain unsupported.

## Validation

- Ray 2.59.0 unit and contract checks passed on Python 3.12 and 3.13.
- Hive 4.2.0 integration and all three planned Ray 2.59.0 cluster scenarios passed
  against this implementation.
- Package build, Twine, installed metadata, imports, and dependency checks passed.

## Scope

This release updates compatibility and release metadata. It preserves the HS2-only
read path, strict no-replay behavior, and existing experimental boundaries.
